## 一、 为什么需要本地第三方代看？
长期居住海外，国内的房产即使处于空置、出租或委托托管状态，隔着时差与距离，依然难以及时了解现场情况：
- **能看一眼现场**：很久没有收到房屋门外、小区的近景照片；
- **减少麻烦亲友**：不方便频繁回国，也不希望因日常查看房屋外观的小事频繁打扰国内亲友；
- **补充了解公开信息**：希望有本地可信的人帮忙顺便看一眼周边房屋公开挂牌价与近况。
